Version 2.7.0 (build 182)

Install PatataTube

Open this page in Safari — other browsers cannot start an install. Then confirm on the Home Screen prompt.

What’s new

Resume playback and quicker access to app info

• Videos can opt in to remembering playback position, with a resume/start-over prompt when you come back
• Added an About item to the options menu

Updating later

Add this page to your Home Screen (Share → Add to Home Screen). The Install button always installs the newest release, so one tap updates the app in place — your downloads and settings are kept.

Requirements

Your device must be registered on the developer account before a build is made. A device added afterwards needs a fresh ./deploy before it can install. iOS 18.0 or later.
